Fixing the Instagram overlay

1080×1920 reels drawn at quarter size. Green dashed = Instagram's safe area (top 220px, bottom 450px, sides 60px, right icon column 140px). Red = what's broken today.

1 · Drop the fake status bar

  • The viewer's real phone already shows one; two clocks look broken.
  • Fill the top 220px with the brand wall + "Mummy is typing…" instead.

2 · Inset the phone 5% each side

  • Render the 412px phone into a ~1020px-wide card (≈56px margins).
  • Survives Instagram's crop on tall screens; bubbles never touch the edge.

3 · Keep the keyboard as filler

  • It sits under the caption and icons, which is fine: it's meant to be covered.
  • Rule: the newest message and input bar must end above y≈1180 (62%).

4 · Check it automatically

  • Add a ?safe=1 overlay to engine/index.html and draw it on the contact sheet.
  • npm run check fails if a bubble's box enters the red zones.
